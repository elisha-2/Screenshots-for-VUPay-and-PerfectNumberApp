# Screenshots for VUPay and PerfectNumberApp

This repository contains user interface **screenshots** for two mobile applications:

1. VUPay – Screenshots demonstrating key screens and workflows.
2. **PerfectNumberApp** – Visuals showing the UI of the Perfect Number application.

These assets can be used for documentation, presentations, design reviews, or app listing pages.

## Repository Structure
Screenshots-for-VUPay-and-PerfectNumberApp/
├── Screenshots for VUPay and PerfectNumberApp/
│ ├── VUPay/
│ │ ├── screenshot1.png
│ │ ├── screenshot2.png
│ │ └── …
│ └── PerfectNumberApp/
│ ├── screenshot1.png
│ ├── screenshot2.png
│ └── …
└── README.md


*Each subfolder contains PNG images captured from the respective app’s user interface.*

## Included Screenshots

### VUPay
Screenshots in this folder demonstrate parts of the VUPay app such as:
- Home screen
- Payment screens
- Transaction history
- Any relevant UI flows

### PerfectNumberApp
Screenshots here include:
- Main app interface
- Input and output screens
- Any visual UI elements relevant to the Perfect Number logic

##  How to Use

1. Click into the appropriate folder to view screenshots.
2. Screenshots are named according to their content (or sequence).
3. Use these images in documentation, app store listings, project reports, or UI reviews.

## Notes

- All screenshots are in `.png` format.
- Ensure that when embedding in web pages or docs, paths are relative (e.g., `./Screenshots for VUPay and PerfectNumberApp/VUPay/screen1.png`).
